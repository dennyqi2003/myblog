## 和弦的变化

### sus2与sus4

三和弦的`sus2`和`sus4`不会带来功能上的明显变化，但可以带来一些微妙有趣的装饰。这种装饰通常可以用在连续多个相同和弦，但又需要变化的情景。

### add2与m7

大三和弦升级为`add2`，小三和弦升级为`m7`，通常不会带来听感和功能上的明显变化。使用`add2`和`m7`往往会营造一种更为流行的听感，与纯净和弦的“古典”听感相对应。例如，流行音乐中大量使用`add2`和`m7`的分解琶音来伴奏：

<img src="C:\Users\DennyQi\AppData\Roaming\Typora\typora-user-images\image-20260212223419299.png" alt="image-20260212223419299" style="zoom: 80%;" />

### add6

当我们想要增加大和弦的色彩时，一般的做法是堆叠大和弦。另一种做法是使用add6。add6也不会改变和弦的功能。由于它的存在已经使大和弦接近于五声音阶，所以可能会有中国风的听感。add6的常见用法是在长时间的大和弦不变时用于与原始和弦交替使用增加活泼性。另外，在想要使用大七和弦增加清澈感，但是旋律音却是和弦根音时，此时大七和弦的最高音和旋律音之间会产生小二度的冲突。此时一个解决方法就是把七度音替换为六度音，也能取得类似的效果。

Cadd6再额外增加九度音，称为C69和弦。同样具有和大七和弦类似的明亮、柔和且带有一点不和谐色彩。

### 属和弦的变化

属和弦向上堆叠恰好会构成混合利底亚音阶（自然大调降第7级音），因此混合利底亚通常可以作为属和弦的旋律声部。它的听感稳重、自然，有民谣或早期摇滚乐的感觉。

<img src="C:\Users\DennyQi\AppData\Roaming\Typora\typora-user-images\image-20260210004111313.png" alt="image-20260210004111313" style="zoom: 33%;" />

在属和弦里，为了增加听感的变化，我们通常可以对其五级音或九级音进行上下半音的变化。这产生了以下八种属九和弦的变化：

### ![image-20260210005727901](C:\Users\DennyQi\AppData\Roaming\Typora\typora-user-images\image-20260210005727901.png)

当我们抛掉原本的五级音和九级音，加入所有的四个变化音，我们得到了一个音阶，这个音阶就称为变化音阶(Altered Scale)：

<img src="C:\Users\DennyQi\AppData\Roaming\Typora\typora-user-images\image-20260210004315831.png" alt="image-20260210004315831" style="zoom:33%;" />

变化音阶高度半音化，产生不协和的听感。并且它剔除了主音上方的纯五度，因此产生不稳定的听感。与混合利底亚音阶相比，它更具有现代感。

同时，从属和弦向主和弦解决的角度看，因为音阶中存在$\sharp D$和$\sharp F$，它相比于混合利底亚具有更强烈的解决到主和弦的倾向。

有时为了方便记忆Altered Scale，可以把它看作“第二级音分裂为了上下半音的全音阶”，也可以把它看作“主音升半音后的旋律小调音阶”。

---

另一种变化属和弦的方法是，给定一个属七和弦（通常省略五音），然后在上面随便堆叠一个三和弦。一般没有一套固定的理论来告诉我们属七和弦上方叠加什么三和弦效果会比较好。通常，这样的做法的目的就是带来一种复杂、纠结的听感，具体什么效果比较好需要看具体需求而定。在此基础上，还可以在堆叠一个三和弦后省略属七和弦的最低音，制造一种更飘逸的听感。在选定一个和弦以后，也可以连续使用整体的半音下行来制造更复杂的听感。

## 和声的功能

不同和弦在乐曲中的功能(function)是不同的。“功能”是指和弦的听感，比如“稳定的”，“温馨的”，“紧张的”，“刺耳的”等等。人们总结出了一些关于和弦功能的基本理论，这些理论可以用于安排悦耳的和声进行。

### 大调式功能体系

选定C自然大调音阶。1是主音。主音上的三和弦C: 1-3-5有“稳定”“在家”的感觉，我们把这种功能称为“主功能”。

5是属音。属音上的三和弦G: 5-7-2听感上倾向于向1-3-5解决，这种功能称为“属功能”。

> “5-7-2倾向于向1-3-5解决”是一种听感。我们可以这样解释这种听感：5-7-2中包含导音7，它有强烈地向1解决的倾向。

4是下属音。下属音上的三和弦F: 4-6-1在听感上适合连接在1-3-5之后，也倾向于解决到5-7-2，这种功能称为“下属功能”。

一个最基本的和声进行模式就是“主-下属-属-主”，它在听感上连贯，有始有终。根据英文首字母，这一进行写为T-S-D-T。

属功能进行到下属功能在听感上是奇怪的，一般不会用这种进行。

我们只为1,4,5上的三和弦定义了功能，那么2,3,6,7上的三和弦的功能是什么呢？Hugo Riemann提出一个见解，认为这些根音上和弦的功能虽然与主、下属、属的功能有差异，但与其给每个根音上的三和弦都定义一个功能，不如把其它和弦都归为这三类功能中去，但是要做强弱的区分。

我们把大调音阶上的顺阶三和弦的功能及常用的TSDT模式总结如下表：

| 主              | 下属     | 属   | 主       |
| --------------- | -------- | ---- | -------- |
| C               | F        | G    | C        |
| C$\to$Em        | Dm       | G7   | Em$\to$C |
| C$\to$Am        | F$\to$Dm | Bdim | Am$\to$C |
| C$\to$Em$\to$Am | Dm$\to$F |      |          |
| C$\to$Am$\to$Em |          |      |          |

## 和弦进行

### 终止式

由五级和弦接到一级和弦作为结束的和弦进行称为“正格终止(authentic cadence)”。由四级和弦接到一级和弦作为结束的和弦进行称为“变格终止(plagal cadence)”。由五级和弦作为结束的和弦进行称为“半终止(half cadence)”。由五级和弦接到非一级和弦作为结束的和弦进行称为“阻碍终止(interrupted cadence)”，在古典音乐里的阻碍终止的“非一级和弦”一般是“六级和弦”。

正格终止最简单的写法就是由五级三和弦或属七和弦接到一级三和弦，这样的写法听感非常古典：

### 那不勒斯和弦(Neapolitan Chord)

那不勒斯和弦是指一个音阶的第二级音降半音上的大三和弦。它在功能上可以看作下属和弦。无论是大调音阶还是小调音阶，它总是会包含这个音阶的下属音。在古典音乐里，小调音阶的那不勒斯和弦经常以第一转位的形式被使用。例如贝多芬的月光奏鸣曲第一乐章里使用了那不勒斯和弦第一转位（如下图）。小调音阶的那不勒斯和弦第一转位根音恰好和下属和弦相同，但却是一个大三和弦，这就在黯淡凄凉的小调环境中产生了一种“明亮的悲叹”的色彩。18世纪意大利那不勒斯的歌剧中，作曲家经常用这个和弦来表达主角极度的绝望、震惊、悲痛或是面临死亡的瞬间。

### 副属和弦(Secondary Dominant)

当一个和弦进行到另一个和弦时，可以在衔接时插入后方和弦根音上方五度音上的属七和弦，这个属七和弦就称为副属和弦。例如下图中，$C$进行到$Em$时，用$E$上方的五度音$B$上的属七和弦做衔接（这里省略了$B^7$的五音）。简单来说，副属和弦正是利用了属和弦具有向主和弦解决的倾向来完成衔接的：通过把$Em$看作临时的主和弦，$B^7$就是相对于$Em$的属和弦，因此成为“副属和弦”。

### 副导和弦

副属和弦如果是属七和弦，此时省略它的根音会得到一个减三和弦，这个减三和弦的根音恰好是目标和弦所形成的音阶上的导音，因此可以称为“副导和弦”。其功能和原理和副属和弦是完全类似的。

### 副下属和弦

变格终止是四级和弦接到一级和弦。利用这个原理，我们也可以在一个临时主和弦前方接四级和弦，这就是副下属和弦。

### 三全音代理(Tritone Substitution)

使用副属和弦做衔接利用的是属和弦具有向主和弦解决的倾向。这种倾向主要来自于属和弦三级音和七级音之间不协和的增四度（减五度），增四度也就是“三全音”。如果把这种解决倾向仅仅看作是由属（七）和弦里的这一增四度造成的，那么我们总是可以选择另一个含有同一增四度的属（七）和弦来替换副属和弦。例如在上面的例子里，原本利用副属和弦$B^7$做衔接，$B^7$中的增四度是$\sharp D-A$，同样含有$\sharp D-A$的属七和弦是$F^7$。所以我们可以把上面的$B^7$替换为$F^7$，这就是“三全音代理”。

注意到，用作三全音代理的那个属七和弦恰好是终点和弦上方半音上的属和弦。于是，三全音代理的规律就可以总结为：可以使用上方半音的属和弦来做衔接。例如：

### 二-五-一

既然副属和弦是把终点和弦看作临时的主和弦，那么我们还可以在副属和弦之前再额外插入一个下属功能和弦。常用的下属功能和弦是四级和二级，在流行音乐里通常二级更常用。这个衔接就称为“二-五-一”。其中，“二”用哪种和弦由临时主和弦是哪种和弦来决定。当临时主和弦是大和弦时，大调音阶的二级顺阶和弦恰好是小和弦，因此此时“二”用小和弦；当临时主和弦是小和弦时，小调音阶的二级顺阶和弦恰好是减和弦，因此此时“二”用减和弦。例如：

### 恒定结构(Constant Structure)

给定旋律配和声时，一般的思路是先确定旋律的调性，然后在这个调的顺阶和弦上做选择。在爵士里，有一种称为恒定结构的配和弦思路，意思是使用同一种结构的和弦（比如属九和弦）随着旋律做平移来配和弦。这种方法对于结构较为复杂的和弦（九和弦及以上）比较有效。
